# Open Bot Avatar material sources

The TypeScript sources in this directory come from the material and geometry code in [Open Bot Avatar 646793af2c86604539e02faa344e9793ab2aefe8](https://github.com/DominikScholz/open-bot-avatar/tree/646793af2c86604539e02faa344e9793ab2aefe8/packages/core). See the upstream [MIT license](LICENSE). The self-hosted build bundles the WebGL2 material entry points with the Codex Web texture adapter.
