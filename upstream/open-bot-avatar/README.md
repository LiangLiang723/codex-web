# Open Bot Avatar material sources

The TypeScript sources in this directory come from the material and geometry code and its dependencies in [Open Bot Avatar 0.5.2](https://github.com/DominikScholz/open-bot-avatar/tree/e10afe49d46da8ffcc6545f5d6e8ba1de4ea8c5d/packages/core). See the upstream [MIT license](LICENSE). The self-hosted build bundles the WebGL2 material entry points with the Codex Web texture adapter.
