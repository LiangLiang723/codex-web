# Codex Web 品牌

`BotAvatar` 为静态标志和动画提供同一个可缩放 SVG 入口。本机研究预览由文档声明带哈希的播放器模块，播放器独立更新自身 SVG。通过造型、配色和缩放参数定制会话实例。轮廓与眼睛参数同属外形，造型选项使用正面投影，播放沿用原始关键帧和球面可见性。会话内播放遵循减少动态效果偏好。`BotStudio` 通过属性接收浏览器的桌宠偏好和写入回调，状态图鉴使用独立播放器展示、筛选和重播 53 个状态。

`ConversationPet` 在会话窗格提供的草稿、右栏和输入区锚点之间移动。会话窗格从既有主会话投影确定活动和结束事件。自动镜像读取会话框相对桌宠落点的水平位置，手动朝向使用浏览器偏好；`BotAvatar` 镜像 SVG 并同步镜像视线坐标。桌宠在本地拥有空闲、唤醒、倾听和手势的动画时序，投影活动变化会清理本地计时器。桌宠设置由 UI store 持有并保存在浏览器里。Bot 不读取或修改任务、消息、远端连接或设置服务。

`usePetBehavior` 持有短时心情和有截止时间的本地动作。性格、自主反应和全部自主动作来自浏览器偏好。完整轮次读取已加载播放器的状态注册表，在一个播放轮次内记录已经完成的状态；播放结束才消耗该状态。在前台小睡后自行醒来，继续此轮。工作行读取会话活动序列，桌宠可以短暂停在加权选出的表情后接回同一序列。活动和会话变化、隐藏页面及减少动态效果都取消自主反应。

UI store 持有颜色和材质偏好，并把两者投影到文档根。启动壳使用同一条保存记录初始化投影。页面内所有 `BotAvatar`、原版启动动画与标签图标读取该投影。Anatomy 仍生成每一帧的 SVG，身体与眼睛分别使用共享纹理；各入口继续提供自己的造型、眼睛轮廓、动作和缩放。绒毛和玻璃各有独立的懒加载资源，等待、加载失败或 WebGL2 不可用时使用当前颜色的纯色 SVG。切换颜色或材质保留播放器与当前播放进度，卸载时释放实例对共享绘制的订阅。
